title: "Sharing and exporting reports"
description: "Share reports with teammates, publish a public link, and export to PDF or Word."

---

Open the share dialog from the **Share** button in the report's top bar. The button is visible to users with edit or owner permission on the report.

## Share with teammates

In the **Share with users** section, search for teammates in your organization and grant each one a role:

- **Can view** — read the report, but not edit or share it
- **Can edit** — edit the report content and manage sharing
- **Owner** — the report's creator; full control

The access list below shows everyone with access and their role. Use it to change a role or remove someone's access. If someone's access is removed while they have the report open, they see a notice and are returned home.

<Note>
Reports are shared per user or via the public link. There is no option to share a report with your entire organization at once.
</Note>

## Publish a public link

The share dialog has a visibility selector:

- **Private** — only invited users can access the report
- **Public** — anyone with the link can view the report

Switching to **Public** generates a share link and shows "Report is now public." Copy the link with the copy button. Anyone who opens it can read the report without a Merciv account. Public visitors get read-only access to the report and the sources it cites; they can never edit.

Switching back to **Private** shows "Report is now private — The public link no longer grants access." Old links stop working immediately.

<Warning>
Turning a report private revokes the public link for everyone, instantly. If you make it public again later, a new link may be issued, so previously shared links may no longer work. Re-share the current link to be safe.
</Warning>

## Export to PDF or Word

From the download button in the report's top bar, choose:

- **PDF** — you'll see "PDF Exported!" when it completes
- **Word Doc** — you'll see "Report Exported!" when it completes

Exports include the current document content.

<Tip>
If an export fails, try the other format. Very large or unusually formatted documents occasionally fail in one format but succeed in the other.
</Tip>
