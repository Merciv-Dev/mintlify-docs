Reports are rich-text documents you write and edit inside Merciv, similar to a document in Notion or Google Docs. Use them to turn research, chat findings, and analysis into polished documents you can share with your team or publish as a link.

Reports support real-time collaborative editing, cover images, inline sources and citations, export to PDF or Word, and public sharing. For sharing and export details, see [Sharing and exporting](/reports/sharing-and-exporting).

## Create a report

<Steps>
  <Step title="Open the creator">
    Click **New** and choose **Report** ("Create a document"). Merciv creates a report named "Untitled Report" and opens it.
  </Step>
  <Step title="Name it">
    Click the title to rename it inline.
  </Step>
  <Step title="Start writing">
    Use the formatting toolbar pinned to the top of the document to structure your content.
  </Step>
</Steps>

You don't always start from a blank page. When Merciv completes a research task for you, the result can arrive as a report, with an activity panel showing the research steps behind it. From there you edit it like any other report.

<Note>
Creating a report inside a project requires editor access to that project. If you only have view access, you'll see "You need editor access to create reports in this project."
</Note>

## Edit and collaborate

Editing requires **Can edit** or **Owner** permission on the report. Editors get:

- A formatting toolbar at the top of the document
- Inline renaming of the title
- Cover image controls

Multiple people can edit the same report at the same time. Everyone currently in the document appears in the header, and edits show up for all collaborators in real time.

If the collaborative editing session can't be established, the report opens read-only with a banner: "The report is temporarily unavailable, you cannot edit this report." Click **Refresh** to retry.

Viewers without edit permission see a read-only version of the document.

## Cover images

Every report can have a cover image at the top. From the cover controls you can:

- Upload an image
- Paste an image link
- Generate a cover with AI
- Remove the current cover

## Organize reports in projects

Reports created inside a project belong to that project; reports created elsewhere are standalone. Keeping a report in a project puts it alongside the chats, files, and other work it draws from. See [Projects](/projects/overview).
