Reports are rich-text documents you write and edit inside Merciv, similar to a document in Notion or Google Docs. Use them to turn research, chat findings, and analysis into polished documents you can share with your team or publish as a link.

Reports support real-time collaborative editing, cover images, inline sources and citations, export to PDF or Word, and public sharing. For sharing and export details, see [Sharing and exporting](/reports/sharing-and-exporting).

## Create a report

<Steps>
  <Step title="Open the creator">
    Click **New** in the top bar and choose **New Report**. Merciv creates a report named "Untitled Report" and opens it.
  </Step>
  <Step title="Name it">
    Click the title to rename it inline.
  </Step>
  <Step title="Start writing">
    Use the formatting toolbar pinned to the top of the document, or type **/** to insert headings, lists, tables, images, and more.
  </Step>
</Steps>

You don't always start from a blank page. When Merciv completes a research task for you in chat, the result can arrive as a report, with an activity panel showing the research steps behind it. From there you edit it like any other report.

<Note>
Creating a report inside a project requires editor access to that project. If you only have view access, you'll see "You need editor access to create reports in this project."
</Note>

## Edit and collaborate

Editing requires **Full access** (Editor) or Owner permission on the report. Editors get:

- A formatting toolbar at the top of the document — text styles, fonts and sizes, bold, italic, underline, highlight, text color, alignment, lists, quotes, code, images, tables, and links
- A **/** menu for inserting blocks: headings, bullet, numbered, task, and toggle lists, blockquotes, code blocks, tables, images, web sources, columns, and dividers
- **Convert links to sources** in the toolbar, which finds the links in the document and turns them into cited sources
- Inline renaming of the title
- Cover image controls

Multiple people can edit the same report at the same time. Everyone currently in the document appears in the header, and edits show up for all collaborators in real time.

If the collaborative editing session can't be established, the report opens read-only with a banner: "The report is temporarily unavailable, you cannot edit this report." Click **Refresh** to retry.

Viewers without edit permission see a read-only version of the document.

## Cover images

Every report can have a cover image at the top. Click **Add Cover**, then choose:

- **Upload Image** — upload a file from your computer
- **Link Image** — paste an image URL
- **Generate Image** — create a cover with AI
- **Delete Cover** — remove the current cover

## Manage a report

The **...** menu in the report's top bar offers:

- **Rename** and **Move to Project** — available to editors and the owner
- **Share** — opens the share dialog (see [Sharing and exporting](/reports/sharing-and-exporting))
- **Delete** — available to the owner only. Deleted reports can't be restored from the app.

## Organize reports in projects

Reports created while you're inside a project belong to that project; reports created elsewhere are standalone. Use **Move to Project** to change where a report lives. Keeping a report in a project puts it alongside the chats, files, and other work it draws from. See [Projects](/projects/overview).
