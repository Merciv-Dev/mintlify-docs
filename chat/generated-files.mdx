When the assistant produces a file — a spreadsheet, a slide deck, a document, a visualization — it appears in the response so you can open and download it without leaving the chat.

## File cards in responses

Files generated by (or attached to) a message show as **file cards** in the response. Images appear as inline thumbnails with a hover download button.

Interactive visualizations can render directly in the message as live dashboards with charts, tables, and metric tiles. If a visualization can't load, the message falls back to a plain file card so you can still open or download the underlying file.

A few things you might see on file cards:

- A loading skeleton while the file is still being generated. Large files and long analyses can take a few minutes.
- **File unavailable** — the assistant referenced a file that never finished generating. Send the request again to regenerate it.

## The full-page file viewer

Click a file card to open the file in a full-page viewer, with built-in viewers for CSV tables, images, PDFs, and HTML. From the viewer you can:

- **Copy Content** — copy the text of text-based files to your clipboard
- **Download** — save the file to your computer
- **Return to chat** — go back to the conversation

For Markdown and plain-text files, the download offers a choice of format: export as a **Word Doc** or keep the original file format.

<Note>
File links refresh automatically before download, so they don't go stale mid-session. If you return to an old file much later and see "File not found — The file may have expired or been removed," re-run the request in chat to regenerate it.
</Note>

## Generated files and Artifacts

Outputs the assistant produces in chat — documents, spreadsheets, slides, images, and interactive dashboards — are saved as [Artifacts](/artifacts/overview). An artifact has its own page outside the chat, with sharing and version history, so it's the way to hand off the assistant's work: chats are private to you, but artifacts can be shared with teammates.

You don't create artifacts manually; they come from what the assistant generates.
