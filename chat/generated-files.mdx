When the assistant produces a file, such as a spreadsheet, slide deck, document, image, or visualization, it appears in the answer so you can open and download it without leaving the chat.

## File cards in answers

Files generated by (or attached to) a message show as **file cards** in the answer. A files chip under the answer lists them all, and a running count appears in the top-right corner of the answer while the assistant works.

Images appear as inline thumbnails. Click one to preview it larger, or hover over it to download it.

Interactive visualizations can render directly in the message as live dashboards with charts, tables, and metric tiles. If a visualization can't load, the message falls back to a plain file card so you can still open or download the underlying file.

A few things you might see on file cards:

- A loading placeholder while the file is still being generated. Large files and long analyses can take a few minutes.
- **Couldn't find this file. Ask for it again.** The assistant referred to a file that never finished generating. Send the request again to regenerate it.

## Opening a file

What happens when you click a file card depends on the file:

- **Most deliverables open as an [artifact](/artifacts/overview).** The artifact page has its own sharing and version history. On desktop, if you were using full-screen chat, the conversation moves into the side panel so it stays visible.
- **Other files open in a full-page file viewer.** It can show images, videos, PDFs, Office documents, HTML pages, CSV tables, JSON, and Markdown. Other file types offer a download instead.

From the viewer's **"..."** menu you can:

- **Download** the file to your computer
- **Export as Word doc**, for Markdown and plain-text files
- **Copy content** to your clipboard, for text-based files
- **Return to chat**, to reopen the conversation in the side panel

<Note>
File links refresh automatically, so they don't go stale while you work. If you return to an old file much later and see "File not found — The file may have expired or been removed," run the request again in chat to regenerate it.
</Note>

## Generated files and Artifacts

Outputs the assistant produces in chat, such as documents, spreadsheets, slides, and interactive dashboards, are saved as [Artifacts](/artifacts/overview). Chats are private to you, but you can share artifacts with teammates. That makes artifacts the way to hand off the assistant's work.

You don't create artifacts manually; they come from what the assistant generates. When you ask the assistant to change a file it made earlier in the same chat, it adds a new version to the same artifact instead of creating a separate one.

To use an image the assistant created, download it from the chat, or ask the assistant to place it in a deck, document, or dashboard.
