Most issues resolve with a retry or a page refresh — Merciv does much of its work in the background, and a dropped connection can make finished work look stuck. Work through the relevant section below. If a problem persists after the suggested steps, contact [hello@merciv.com](mailto:hello@merciv.com) with the page you were on, what you clicked, and the approximate time.

## Uploads and file processing

### A file is stuck processing

While a file is being processed, Knowledge shows it as **Understanding** (or **Processing...**). Files aren't usable by chat or search until background processing finishes. Processing normally takes a few minutes; large or scanned documents take longer because every page is processed individually.

**What to try:**

- Refresh the page — if your connection dropped mid-processing, the file may already be done and the screen just didn't update.
- Wait a bit longer for large PDFs or decks. Some stalled files recover on their own within a retry window.

If processing can't complete, the file shows **Failed**, and the upload tray says "Processing failed. Try uploading this file again." Re-upload the file once. If a file is still processing after about 30 minutes, or fails again after a re-upload, contact support with the file name — the Merciv team can re-run processing for you.

### An upload failed

"Could not upload" or "Failed to upload" usually means the transfer failed partway; any partial file is cleaned up automatically.

**What to try:**

- Use **Retry** in the upload tray. Retry only works before you reload the page, so retry first, refresh second.
- If you see **"Your knowledge storage is full"**, your organization has reached its plan's storage limit. Delete files you no longer need, or ask an organization admin to request more storage. See [Billing and plans](/admin/billing-and-plans).
- If you see "No active organization. Please refresh and try again," refresh the page and upload again.
- If the tray says "You do not have permission to upload to this knowledge base," you can't change that base. Upload somewhere you can, or ask the base's owner for access. See [Uploading files](/knowledge/uploading-files).

If uploads keep failing across retries and files, contact support.

### A file was rejected before uploading

Knowledge uploads are validated in your browser, so rejections are immediate:

- **"Invalid file type"** — Knowledge accepts PDF, Word, PowerPoint, Excel, CSV, Parquet, SPSS (`.sav`), Markdown, and images (jpg, jpeg, png, webp). Convert other formats before uploading. Plain-text, HTML, XML, and JSON files can still be attached directly in [chat](/chat/sources-and-attachments).
- **"File too large"** — the standard limit is 100 MB per file (the message shows your organization's limit). Split or compress larger files.
- **"Too many files"** — a single upload is capped at 2,500 files. Split into multiple uploads.
- **"Upload too large"** — a single upload can't exceed 25 GB in total. Files over the budget aren't added; upload them separately.
- **"Invalid file"** ("...does not match its file type") — the file's contents don't match its extension, usually because it was renamed or is corrupted. Re-export it from its source application.
- **"Empty file"** — 0-byte files are rejected. Check that the file opens locally.

Rejected files don't block the rest of the batch — valid files in the same selection still upload. See [Uploading files](/knowledge/uploading-files) for the full limits.

## Chat

### A response stalls or stops mid-stream

Chat replies stream to your browser live, so a network interruption (laptop sleep, switching Wi-Fi) can cut the stream even though the answer finishes on Merciv's side.

**What to try:**

- Refresh the page. The completed response often appears.
- If it doesn't, resend the message.
- In **Deep research** mode, a long-running activity timeline is normal — deep research typically takes 5–15 minutes.

If chat is unresponsive for everyone on your team at once, contact support — that points to a platform issue rather than your connection.

### "Task failed" appears in a response

A background task the assistant was running errored or was interrupted. Retry the request in the same chat. If the same request fails repeatedly, contact support with the chat and the prompt you used.

### "File unavailable" on a citation

A cited source file couldn't be loaded — it may have been removed, or you may no longer have access to it. Deleted sources show "(deleted)" next to their name. Ask the file's owner to share it again, or re-upload it if it was yours.

### "Unable to load file" or "File not found — The file may have expired or been removed"

Links to chat files can expire. Return to the chat and open the file again; if the file is gone, re-run the request to regenerate it.

### Attachment errors when sending a message

Chat attachments are validated per message:

- **Maximum 5 files** per message, **25 MB per file**, **100 MB combined**.
- Duplicate file names, empty files, and unsupported types are rejected individually — the rest of your files still attach.

Remove or resize attachments to fit the limits, then resend. See [Sources and attachments](/chat/sources-and-attachments).

### "Failed to send message"

The send didn't go through, usually a momentary network or service hiccup. Retry — it typically works on the second attempt. If you see "No active organization found," reload the page first.

### "You've used all your credits"

Your organization's shared credits have run out for this cycle, so new messages can't be sent. Organization admins see a **Request Access** button to reach the Merciv team; other members should contact their organization's administrator. See [Billing and plans](/admin/billing-and-plans).

### "Upgrade to keep chatting" or "Request access to continue"

Your organization's plan no longer includes access to Merciv, so sending messages (including [Playbook](/playbooks/overview) runs) is blocked. Click **Request Access**, switch to another organization if you belong to one, or contact your Merciv representative.

## Trackers and stories

### A run shows Failed

Hover the run's status for the reason. The most common: the tracker's topic was judged too vague or placeholder-like to research (for example, "test"). Edit the tracker with a concrete monitoring brief — a real topic or question — and run it again. If a well-formed tracker fails repeatedly, contact support.

### A run shows Skipped

Skipped is not an error. It means the run found no new topics for the period, or every candidate overlapped with stories the tracker already published — deduplication working as intended. If it happens often, broaden the topic, add sources, or lower the frequency. See [Managing trackers](/trackers/managing-trackers).

### "Story generation triggered" but no story appears

Story generation is background work that can take several minutes; the tracker page keeps checking for up to 30 minutes. Check the run's row on the tracker page — the run may still be going, or it may have ended Skipped. If a run shows Success but no story ever appears, contact support.

### A scheduled run didn't happen

Check, in order:

- The tracker's status is **Active** (not Paused).
- The card's "Next run" time — schedules fire on the hour and half hour in the tracker's timezone, so a run can be up to 30 minutes later than you expect.
- The tracker isn't set to **Manual**, which never runs on its own.

If an Active tracker with a valid schedule misses runs, contact support.

### "You're tracking as much as this plan allows"

Your organization has reached its plan's tracker limit. Archive trackers you no longer need, or contact your Merciv representative about a higher limit.

### "Tracker not found"

The tracker was deleted, the link is wrong, or you don't have access — organization trackers are visible only to organization admins. Archived trackers are permanently deleted after 30 days.

## Sharing and access

### "No access" when opening a link from a teammate

What this means depends on what was shared:

- **Chats can't be shared at all.** A chat is visible only to the person who created it. To share chat output, share the [generated artifact](/artifacts/overview) or create a [report](/reports/overview) instead.
- **Projects, reports, and artifacts** must be shared with you, either directly or through a project they belong to. Ask the owner to open **Share** and invite you.
- **Wrong organization** — if you belong to more than one organization, confirm the right one is active. Content is scoped per organization.

If the owner has shared the item with you and you still can't open it, contact support.

### A public link stopped working

Public links are controlled by the owner and stop working the moment sharing is turned off:

- **Reports** — "Report Access Denied" means the share link is invalid or the owner switched off **Anyone with the link**. Turning it back on creates a new link, so ask the owner for the fresh one.
- **Stories** — a story link shows "Story Not Available" when the story is private. Ask the owner to make it public.
- **Artifacts** — "Artifact not available" means the public link was turned off or the artifact was removed. Ask the owner to re-enable the public link.

A public link never confirms whether the item still exists — private, deleted, and nonexistent items all show the same message.

### "You do not have permission to share this item"

You have view-only access. Only editors and owners can share; ask the owner to change your access to **Full access**.

### "The report is temporarily unavailable, you cannot edit this report"

The collaborative editing session couldn't start, so the report opened read-only. Click **Refresh** in the banner. If the report stays read-only after several refreshes, contact support with the report link.

## Account and login

### Can't log in

- **"Merciv is currently available for work email addresses"** — personal email domains (gmail and similar) are blocked. Click **Try another account** and sign in with your company email.
- **Bounced back to the login page repeatedly** — if your session can't be confirmed, it's cleared automatically so the next attempt starts clean. Try once more; if the loop continues, contact support.
- **The page briefly reloads and returns you to where you were** — Merciv renewed your session in the background. No action needed. If this ends with you being signed out, log in again.
- **Opening Merciv inside another app** (a link tapped in LinkedIn, Instagram, and similar in-app browsers) uses a full-page login instead of a popup. If login misbehaves there, open the link in your regular browser.

### Stuck on "Check Your Email"

Merciv requires email verification before you can enter the app. Check your inbox and spam folder for the verification email, click the link, then click **I've Verified My Email**. If the email never arrives, contact support. See [Getting access](/account/getting-access).

### "You're on the waitlist!"

You signed up without a pending invite, an approved email domain, or an invite code. Check that:

- Any invite was sent to the **exact** email address you signed in with — aliases and misspellings don't match.
- If you were given an invite code or signup link, you used it during signup.

Otherwise ask an organization admin to invite you from **Settings → Members**, or contact your Merciv representative.

### "You don't have access to any organizations yet"

Your account exists but doesn't belong to an organization — typically after being removed from your only one. An organization admin needs to invite you.

### A feature is missing from your navigation

Some features — including Playbooks, Portfolio, Galleries, Integrations, and certain chat options — are available on select plans. They may not appear for your organization, or may appear with a lock and a **Request Access** option.

<Note>
If you expect a feature and don't see it, contact your Merciv representative. Feature availability is set per organization, so teammates at other companies may see options you don't.
</Note>

## Members and invites

These apply to organization admins and owners managing people from **Settings → Members**. See [Managing your organization](/admin/managing-your-organization).

### An email invite won't send

- **"User Already Invited"** — that address already has a pending invite. Remove it from the pending list in the invite dialog, then invite again.
- **"Invalid Email"** — check the address for typos.
- **"Your team has outgrown this plan"** or **"You've filled every seat of this type"** — your plan's member or seat limit is reached. Pending invites count toward it, so remove any you no longer need, or choose a seat type that still has room.
- **A generic error as a member** — only organization admins and owners can send email invitations. Share your personal invite link instead, if you have one, or ask an admin.

### A role or seat change is refused

- **"Org Owners and Org Admins require a Full Access seat."** — move the person to a Full Access seat first.
- **"Only an Org Owner can manage another Org Owner."** — ask an owner to make the change.
- **"Assign another Org Owner before changing the last owner."** — every organization needs at least one owner. Make someone else an owner first.

## Errors and app updates

### "This one's on us" (full-screen error)

The app hit an unexpected error. The Merciv team is notified automatically the moment it happens — you don't need to file a report for it to be seen.

**What to try:** click **Retry**, or refresh the browser. That recovers in most cases. A one-off occurrence needs no follow-up; if the error repeats on the same page or action, contact support with the steps that trigger it.

### "Page not found"

The link points to a page that doesn't exist — it may be mistyped or out of date. Click **Go home** and navigate from there, or ask whoever sent the link for a current one.

### "Temporarily offline"

Merciv is down for maintenance. Click **Retry** after a few minutes. If it persists, contact support.

### "A required update is available"

A new version of Merciv has been released and the app reloads itself after a short countdown. Let it finish; you'll be back where you were. You may also see "Updated app to the latest version" after a reload.
