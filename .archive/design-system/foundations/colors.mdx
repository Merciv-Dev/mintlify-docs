All color tokens live in `colors_and_type.css`. Pull values from there — never invent hex codes.

## Neutral scale

Warm foundation, `05`–`100`. Neutrals dominate every layout.

| Token | Hex | Usage |
|---|---|---|
| `--neutral-5` | `#0D0D0C` | Primary text, darkest ink |
| `--neutral-10` | `#1A1917` | Dark mode page surface |
| `--neutral-20` | `#33332F` | Body text, secondary text |
| `--neutral-30` | `#4D4C48` | — |
| `--neutral-40` | `#666560` | Meta, subtle, kickers |
| `--neutral-50` | `#7F7E77` | Muted captions |
| `--neutral-60` | `#99988F` | Separators |
| `--neutral-70` | `#B2B1AA` | Dark mode muted |
| `--neutral-80` | `#CCCBC4` | — |
| `--neutral-90` | `#E5E5DF` | Dividers, secondary button fill |
| `--neutral-95` | `#F2F2ED` | Raised sections, card hover |
| `--neutral-98` | `#FAF9F5` | Page background (cream) |
| `--neutral-100` | `#FFFFFF` | Card fill |

## Orange scale

High-energy accent, `20`–`90`. Core hue: **orange-50 `#ED4421`**.

| Token | Hex |
|---|---|
| `--orange-20` | `#572330` |
| `--orange-30` | `#7C3648` |
| `--orange-50` | `#ED4421` |
| `--orange-60` | `#FF5E3D` |
| `--orange-80` | `#FFA894` |
| `--orange-90` | `#FFCABD` |

Use sparingly. Pair a lighter tint over a darker shade within the family. Never mix with blue in one composition.
