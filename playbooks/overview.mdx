Playbooks are guided workflows built by Merciv for repeatable research and analysis tasks — competitive intelligence, concept testing, and similar work. Instead of writing a long prompt from scratch, you pick a playbook, fill in a short form, and run it. Merciv executes the workflow and returns the answer in a chat conversation, where you can ask follow-up questions like any other chat.

<Note>
Playbooks are available on select plans. If you don't see **Playbooks** in the sidebar, contact your Merciv representative.
</Note>

## Find a playbook

Open **Playbooks** from the left sidebar, or use the **Playbooks** tab on the Home page. The Playbooks page has two tabs:

- **Discover** — the full catalog available to you. When you're browsing all categories, a featured section curated by Merciv appears at the top, followed by the full list. Playbooks are listed alphabetically and load as you scroll.
- **Saved** — playbooks you or your organization have bookmarked, with a filter for **All saved**, **Saved by me**, and **Saved to Org**.

To narrow the catalog:

- **Category filter** — choose from categories such as Brand Strategy, Competitive Intelligence, Concept Testing, Consumer Insights, Digital Audit, Ecommerce, Innovation, Pricing, Retail Strategy, Sales Enablement, Shopper Insights, Social Insights, and Trend Discovery.
- **Search** — matches playbook titles, descriptions, and categories.

<Tip>
Search filters only the playbooks already loaded on the page. If you don't see a match, scroll down to load more of the catalog and search again.
</Tip>

## Save a playbook

Hover over a playbook card to reveal the bookmark button:

- Anyone can choose **Save to my playbooks** to bookmark it for themselves.
- Organization admins also see **Save to org**, which adds the playbook to the whole organization's Saved list.

Saved playbooks appear under the **Saved** tab, scoped by the filter you choose.

## Run a playbook

<Steps>
  <Step title="Open the playbook">
    Click a playbook card. A dialog shows the playbook's title, category, and description alongside a **Configure this playbook** form.
  </Step>
  <Step title="Fill in the inputs">
    Depending on the playbook, inputs can include text fields, dropdowns, multi-select checkboxes (some with hints like "Choose 1-3"), and file uploads. Required fields are marked with an asterisk.

    File uploads accept PDF, DOCX, PPTX, XLSX, CSV, and TXT files up to 25 MB each. Some playbooks cap the number of files per field.
  </Step>
  <Step title="Add extra context (optional)">
    Expand **Additional context** to add any extra instructions or constraints. This text is appended to the run.
  </Step>
  <Step title="Run it">
    Click **Run Playbook**. The button shows a spinner while your files upload and the run is submitted.
  </Step>
</Steps>

<Warning>
Closing the dialog or switching to a different playbook clears everything you've entered, including uploaded files.
</Warning>

## Where results land

Playbook runs happen in [Chat](/chat/overview):

- If you're not already in a chat, Merciv creates a new conversation and takes you to it.
- If you run a playbook from inside a chat, the run is added to that conversation.

Your run appears in the conversation as a card showing the playbook's title, category, and the values you entered. Merciv's answer arrives as a regular chat response, so everything you can do in chat applies — follow-up questions, generated outputs, and conversation history.

Playbook runs use message credits the same way regular chat messages do.

## Adding or changing playbooks

The playbook catalog is curated by Merciv. There's no in-product way to create or edit playbooks — if you'd like a new playbook or a change to an existing one, contact your Merciv representative.
