Knowledge is Merciv's document library. Upload your own files — research decks, survey data, call-center exports, spreadsheets — into **knowledge bases**, and Merciv processes each one so the assistant can search it, summarize it, and cite it when answering questions in [Chat](/chat/overview).

Every file you upload is processed automatically in the background: its content is extracted, summarized, and indexed. Once processing finishes, the file can be used as a source in any conversation.

<Note>
Knowledge is available on select plans. If the **Knowledge** item in the navigation appears locked, click **Request Access** or contact your Merciv representative.
</Note>

## Knowledge bases

A knowledge base is a top-level collection of files and folders with its own access setting. Use one base per topic, team, or project — for example, a base for brand tracking studies and another for competitor research.

Open **Knowledge** from the left navigation to see your bases as cards, each showing its file count and type. Tabs narrow the list:

| Tab | What it shows |
|---|---|
| **All bases** | Every base you can access |
| **Private** | Bases you created that aren't shared with the whole organization |
| **Shared** | Bases a teammate created and shared with you |
| **Organization** | Bases available to everyone in your organization |

Use the search box to find a base by name. Click a card to open it.

<Tip>
If your organization used Knowledge before knowledge bases were introduced, your earlier files are in two bases: **Org Knowledge Base** for organization-wide files and **Private Knowledge Base** for your private files.
</Tip>

## Create a knowledge base

<Steps>
  <Step title="Start a new base">
    On the Knowledge page, click **New knowledge base**. If you don't have any bases yet, click **Add knowledge**.
  </Step>
  <Step title="Name it and choose visibility">
    Enter a **Base name** and pick a **Visibility**: **Private** (only you, until you share it) or **Organization** (everyone in your organization). Base names must be unique.
  </Step>
  <Step title="Create it">
    Click **Create base**. Merciv opens the new base so you can start adding files.
  </Step>
</Steps>

Only organization admins can create **Organization** bases. Anyone can create a **Private** base and later share it with specific people. See [Organizing and sharing](/knowledge/organizing-and-sharing#sharing-a-knowledge-base).

## Who can see and change a base

| Base type | Who can see it | Who can add and change files |
|---|---|---|
| **Private** | Only you | You |
| **Shared** | You and the people it's shared with | You and people with **Full access** (editors) |
| **Organization** | Everyone in your organization | Organization admins |

People with **View only** access (viewers) can open, download, and chat with files but can't upload, rename, move, or delete anything.

## How the assistant uses Knowledge

The assistant can draw on any knowledge you have access to. When you want an answer grounded in specific material, point the assistant at it:

- **A whole base** — open the base and click **Chat** in the header. Merciv starts a new chat scoped to that base.
- **Specific files or folders** — select them in a base and click **Chat with selected** in the toolbar that appears.
- **From the chat composer** — type **@** to add a knowledge base, folder, or file to your message. See [Sources and attachments](/chat/sources-and-attachments).

A few things to know:

- Files that are still processing can't be added to a chat and don't appear in chat search until processing finishes.
- Spreadsheets, CSVs, and other data files are processed as tables, so the assistant can analyze their contents rather than just read them.
- Knowledge holds files you upload. Web pages you add to a single conversation aren't stored in Knowledge, and tools you connect through [Integrations](/knowledge/integrations) are used live in chat rather than stored as files.
