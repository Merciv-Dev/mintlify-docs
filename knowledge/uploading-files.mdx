Upload files into a [knowledge base](/knowledge/overview#knowledge-bases) so Merciv can search, summarize, and cite them in chat. Uploads run in the background, and each file is processed automatically before it can be used as a source.

To upload into a base, you need to be able to change it: you created it, you have **Full access** to it, or it's an **Organization** base and you're an organization admin.

## Supported file types and limits

| Category | Extensions |
|---|---|
| PDF | `.pdf` |
| Word | `.doc`, `.docx` |
| PowerPoint | `.ppt`, `.pptx` |
| Excel | `.xls`, `.xlsx` |
| CSV | `.csv` |
| Parquet | `.parquet` |
| SPSS | `.sav` |
| Markdown | `.md` |
| Images | `.jpg`, `.jpeg`, `.png`, `.webp` |

Limits:

- **100 MB per file.**
- **2,500 files and 25 GB per upload.** Files past either limit are skipped; the rest of the upload continues.
- **Folders nest up to 10 levels**, counting the knowledge base itself.

Merciv checks each file in your browser before uploading it. Empty files, unsupported types, files over the size limit, and files whose contents don't match their extension (for example, a `.zip` renamed to `.pdf`) are skipped. Re-export a mismatched file from its source application and upload it again.

<Note>
Plain text, HTML, XML, and JSON files aren't accepted in Knowledge, but you can attach them directly to a conversation. See [Sources and attachments](/chat/sources-and-attachments).
</Note>

Your organization also has a storage limit based on its plan. If an upload would go over it, the upload is blocked and a **Your knowledge storage is full** dialog appears. Delete files you no longer need or request more storage — see [Billing and plans](/admin/billing-and-plans).

## Upload files

<Steps>
  <Step title="Open the destination">
    On the Knowledge page, open the knowledge base you want, then open the folder the files belong in. Files land in whichever folder is open.
  </Step>
  <Step title="Add your files">
    Click **Upload** in the toolbar and pick your files, or drag files from your computer onto the file list. In an empty base, use the **Upload files** button or drop files onto the drop zone.
  </Step>
  <Step title="Watch the upload tray">
    The upload starts right away and a tray appears in the bottom-right corner showing progress. You can keep working while files upload.
  </Step>
</Steps>

Files take on the access of the base you upload into. To make files available to your whole organization, upload them into an **Organization** base.

### Upload a folder

Click **Upload** and choose **Upload folder**, or drag a folder onto the file list. Merciv recreates the folder's structure as subfolders inside the base. Folders nested deeper than the limit are uploaded into the nearest allowed folder.

<Note>
Folder upload is available on select plans. Without it, dragging a folder in uploads the files it contains without their folder structure.
</Note>

### Save files from a chat

When you send a message with attachments of a type Knowledge supports, Merciv offers to keep them: a card asks **Save N files to a knowledge base?** Click **Select base**, choose a base or folder, and click **Upload**. The files are processed like any other upload, so future chats can find them without re-attaching.

## The upload tray

The tray in the bottom-right corner shows a progress ring for each file and a running count in its header. From the tray you can:

- **Cancel upload** on a file that's still uploading.
- **Retry** a failed upload, or **Retry all** when several failed. Retry only works in the same browser tab — after a page reload, upload the file again.
- **Dismiss** a failed file.
- Review skipped files, grouped by reason — for example, **Too large**, **Unsupported file type**, or **Over the per-upload file limit**.
- Minimize or expand the tray.

Finished files leave the tray on their own. If your connection drops, uploads resume automatically when you're back online. Uploads continue while you move around the app, but they're tied to the browser tab that started them — closing or reloading that tab stops any unfinished uploads.

## Processing

Once a file finishes uploading, Merciv processes it automatically: content is extracted page by page (including text recognition and chart and table analysis for documents), summarized, and indexed. Spreadsheets and other data files are processed as tables so the assistant can analyze them. Processing usually takes a few minutes, longer for large files or large folder uploads.

While a file is processing, its **Date added** column reads **Understanding** and the file stays at the top of the list. When processing finishes, the column shows the date the file was added.

Text recognition supports English, Spanish, French, and Portuguese.

<Note>
Files that are still processing can't be added to a chat and don't appear in chat search until processing completes. You can still delete them.
</Note>

## If a file shows Failed

If processing can't finish, the file's **Date added** column shows **Failed**. Large or unusually complex files are the most common cause. Try uploading the file again; if it fails again, email [hello@merciv.com](mailto:hello@merciv.com) with the file name and knowledge base so the team can look into it.

A file that has been **Understanding** for a long time is usually waiting its turn behind other uploads rather than stuck.

For other upload problems, see [Common issues](/troubleshooting/common-issues).
